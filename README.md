# 题见 · 选题研究工作台

基于 AI Startup Trend Analysis 的三步工作流改造的本地面试原型。
输入关注领域、目标读者与研究方向，生成有来源、有分歧、有证据边界的选题。
本项目是独立原型，与知乎无官方关系，也不提供知乎热度数据。

首次使用请阅读 [使用说明](USER_GUIDE.md)，包含 DeepSeek 配置、完整操作流程和常见问题。

## 启动

当前电脑已安装独立开发环境，在本目录运行：

```powershell
.\start.ps1
```

脚本优先使用项目 `.venv`，其次使用本工作区 `work/topic-lab-venv`。
默认端口 8501，被占用时自动递增。仅监听本机 127.0.0.1。

在其他电脑上，安装 Python 3.12 后：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.ps1
```

也可以运行 `python -m streamlit run app.py --server.address 127.0.0.1`。

## 两种模式

- 样例演示：三组羽毛球话题，分别围绕球拍消费、双打配合与运动损伤。资料摘要、选题和提纲均预先编写，不消耗模型额度、不联网生成；未采集热度数据，不代表实时热榜。界面及导出都标注样例身份。
- 联网研究：DDGS 多后端搜索公开网页（过滤广告跳转）；不限时间的搜索失败时回退到 Bing RSS。最多读取 6 个来源，调用三个 Agno Agent，生成结构化选题。需要模型 API Key。

模型连接支持 Gemini、DeepSeek，以及支持结构化输出的 OpenAI 兼容服务。可以在侧栏填写当前会话密钥，或在本目录创建 `.env`，字段见 `.env.example`。
使用 DeepSeek 时，服务直接选择“DeepSeek”，默认模型为 `deepseek-chat`，API 地址为 `https://api.deepseek.com`，填写 DeepSeek 平台的 API Key 即可。支持独立环境变量 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、`DEEPSEEK_BASE_URL`，不会复用其他服务的密钥。原有“OpenAI 兼容”配置方式仍可用。程序使用 DeepSeek 适配器、`system` 角色和 JSON mode，再在本地校验字段及引用；地址带 `/v1` 也支持。真实可用模型以你的账号为准。
密钥不写入 SQLite、研究结果或导出。不要把 `.env` 提交到 Git；不要把该本地原型直接当成多用户公共服务部署。

默认 Gemini 模型为 `gemini-2.5-flash`，可在界面修改。模型是否可用、费用和额度以你的服务商账号为准。
正常联网研究使用三个顺序模型调用；点击“生成研究提纲”额外调用一次模型，不增加搜索。
联网研究时展开“研究进度”，可查看当前操作、总耗时、当前步骤耗时及真实执行记录。等待模型响应期间持续计时；完成后收起，失败时保留记录。此处展示工作流事件，不展示模型内部思维链，不编造推理或预计剩余时间，也不增加模型调用。

## 架构

```text
Streamlit 输入领域、目标读者、方向
  → 搜索工具获取资料
  → 资料搜集 Agent 筛选来源
  → 读取可访问的网页正文（失败则标注仅搜索摘要）
  → 证据摘要 Agent：证据 + 引用 + 局限
  → 选题分析 Agent：标题 + 讨论价值 + 分歧 + 来源 + 边界
  → 引用编号校验
  → 展示、收藏、反馈、导出
```

这是固定三步工作流，不是自主规划系统。筛选来源的选择由模型完成，步骤顺序由 Python 控制。
网页内容作为数据提供给模型，不作为指令。来源网址由搜索工具提供，模型只能引用已存在的来源 ID。
编号校验只能阻止无效引用，不能保证证据在语义上支持结论，仍需要人工核对。
正文抓取会拒绝内网解析地址。若本机代理使用特殊 DNS 地址，来源可能只能使用搜索摘要，界面会明确标注。免费搜索可能超时或返回低相关性内容，不能承诺来源质量或完整性。

## 文件

| 文件 | 用途 |
| --- | --- |
| `app.py` | 界面、会话状态和交互 |
| `pipeline.py` | 搜索、正文提取、三个 Agent、深挖、导出 |
| `models.py` | 结构化输出约束 |
| `demo.py` | 固定样例，便于离线演示 |
| `storage.py` | SQLite 收藏、反馈、最近 30 条研究记录 |
| `tests/test_core.py` | 引用、存储、导出、流程与失败检查 |
| `upstream/startup_trends_agent.py` | 未修改的原始示例，便于对照 |

本地数据保存在 `.local/library.sqlite3`。收藏、反馈和研究记录会持续保存，刷新页面不会删除。
反馈目前仅供复盘，不会自动优化提示词或训练模型。样例与真实研究记录分别标注。
